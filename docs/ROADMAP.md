# Roadmap

Ids are `R<milestone>.<n>`. `- [ ]` is pending, `- [x]` is done.

## R0 — First version

- [x] R0.1 Engine with one `Request` per tool and a CLI that reaches every tool
- [x] R0.2 Overview: drives (SSD/HDD), memory, `hiberfil.sys` / `pagefile.sys` / `swapfile.sys`
- [x] R0.3 Disk analyzer: parallel scan, folder tree, treemap, largest files, size per extension
- [x] R0.4 Junk cleanup by category, with minimum age, admin detection and honest reports
- [x] R0.5 Program leftovers: folders nothing on the system refers to, moved to the recycle bin
- [x] R0.6 Installed programs with search, sort and their own uninstaller
- [x] R0.7 Startup programs on/off using Windows' own "startup approved" records
- [x] R0.8 Maintenance: component store analysis and cleanup, hibernation on/off
- [x] R0.9 Spanish translation; light and dark themes following the system

## R1 — Next

- [ ] R1.1 Verify every feature on a real Windows 11 machine (only cross-checked so far)
- [x] R1.2 Duplicate files finder (size, then partial hash, then full hash)
- [x] R1.3 Size on disk (compressed and sparse files) next to logical size
- [x] R1.4 Count hard links once, so WinSxS shows its real size in the analyzer
- [x] R1.5 Leftover registry keys of uninstalled programs (report only, export before removing)
- [x] R1.6 Scheduled tasks in the startup page (programs' own tasks; Windows' tasks are never listed)
- [x] R1.13 Third-party services in the startup page (set to manual start, never disabled)
- [x] R1.7 MCP server (`rewind-os-cli mcp`) with `--automation-read-root` / `--automation-write-root`
- [x] R1.8 Live-region announcements when a background job finishes
- [x] R1.9 GitHub Actions: CI on Linux and Windows, release workflow with portable zips (x64, arm64)
- [x] R1.11 MSI installer (WiX) next to the portable zip
- [ ] R1.12 Code signing certificate (Azure Trusted Signing or a .pfx) so SmartScreen does not warn
- [x] R1.10 Faster scans via the NTFS master file table when elevated (drives and the folders right below them; anything else walks the folders)

## R2 — Rewind OS on every system

- [x] R2.1 Rename to Rewind OS (`rewind-os-*`, app id `io.github.rewind_os.rewind_os_app`)
- [x] R2.2 App icon: a disk gauge around a rewind symbol (was a cassette tape, before that an engraved raccoon), generated by `assets/app-icon/draw.py`, rendered by `cargo xtask icons`
- [x] R2.3 Every tool declares its systems; unsupported tools say so in the GUI and the CLI
- [x] R2.4 Known folders per system (XDG on Linux, `~/Library` on macOS)
- [x] R2.5 Cleanup categories for Linux and macOS; recycle bin on Linux and macOS
- [x] R2.6 Linux startup programs (XDG autostart, user overrides only)
- [x] R2.7 Linux maintenance: journal size and vacuum
- [x] R2.8 CI on Linux, Windows and macOS; Linux x64/arm64 tar.gz in releases
- [x] R2.9 Linux: installed programs (dpkg, rpm, pacman, Flatpak, Snap), without libraries and the base system
- [x] R2.15 Linux: uninstall through the package manager (APT simulated first, never taking other packages along; pacman, Flatpak, Snap)
- [x] R2.16 Linux: leftovers of removed programs in `~/.config`, `~/.local/share`
- [x] R2.17 Linux: RPM uninstall (`rpm -e`, checked with `--test` first, never taking dependents along)
- [x] R2.10 macOS: installed apps (`/Applications`, `~/Applications`), uninstalled to the Trash
- [x] R2.18 macOS: leftovers of removed apps in `~/Library/Application Support` and `~/Library/Containers`
- [x] R2.11 macOS: LaunchAgents on and off through launchd's own record (`launchctl disable`), never Apple's
- [ ] R2.20 macOS: login items ("Open at Login"), which need permission to control System Events
- [ ] R2.12 macOS release: `.app` bundle, `.icns`, signing and notarization, `.dmg`
- [x] R2.13 Linux: `.deb` and `.rpm` packages next to the tar.gz
- [x] R2.19 Linux: Flatpak bundle (host filesystem; system tools run on the host)
- [x] R2.14 Linux and macOS: administrator rights for one action at a time (pkexec / authorization dialog), never a root window

- [x] R3.4 Make Windows lighter: reversible settings for ads, suggestions, privacy, extras, effects
- [x] R3.5 Optional removal of preinstalled Store apps (reinstallable from the Store)
- [x] R3.6 Recommendations from leftovers and duplicate files (duplicates in Downloads only, to stay quick)
