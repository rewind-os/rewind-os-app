# Roadmap

Ids are `R<milestone>.<n>`. `- [ ]` is pending, `- [x]` is done.

## R0 — First version

- [x] R0.1 Engine with one `Request` per tool and a CLI that reaches every tool
- [x] R0.2 Overview: drives (SSD/HDD), memory, `hiberfil.sys` / `pagefile.sys` / `swapfile.sys`
- [x] R0.3 Disk analyzer: parallel scan, folder tree, treemap, largest files, size per extension
- [x] R0.4 Junk cleanup by category, with minimum age, admin detection and honest reports
- [x] R0.5 Program leftovers: folders nothing on the system refers to, moved to the recycle bin
- [x] R0.6 Installed programs with search, sort and their own uninstaller
- [x] R0.7 Startup programs on/off using Windows' own "startup approved" records
- [x] R0.8 Maintenance: component store analysis and cleanup, hibernation on/off
- [x] R0.9 Spanish translation; light and dark themes following the system

## R1 — Next

- [ ] R1.1 Verify every feature on a real Windows 11 machine (only cross-checked so far)
- [x] R1.2 Duplicate files finder (size, then partial hash, then full hash)
- [x] R1.3 Size on disk (compressed and sparse files) next to logical size
- [x] R1.4 Count hard links once, so WinSxS shows its real size in the analyzer
- [x] R1.5 Leftover registry keys of uninstalled programs (report only, export before removing)
- [x] R1.6 Scheduled tasks in the startup page (programs' own tasks; Windows' tasks are never listed)
- [x] R1.13 Third-party services in the startup page (set to manual start, never disabled)
- [x] R1.7 MCP server (`rewind-os-cli mcp`) with `--automation-read-root` / `--automation-write-root`
- [x] R1.8 Live-region announcements when a background job finishes
- [x] R1.9 GitHub Actions: CI on Linux and Windows, release workflow with portable zips (x64, arm64)
- [x] R1.11 MSI installer (WiX) next to the portable zip
- [ ] R1.12 Code signing certificate (Azure Trusted Signing or a .pfx) so SmartScreen does not warn
- [x] R1.10 Faster scans via the NTFS master file table when elevated (drives and the folders right below them; anything else walks the folders)
- [x] R1.15 Build folders of software projects (`node_modules`, `target`, virtual environments, Gradle/Maven/.NET/Flutter/CMake output), recognised by the file that proves them
- [x] R1.16 Updates: signed releases (minisign signature of `SHA256SUMS.txt`), a notice in the app when a new version is out, and one-click install for the MSI and the portable builds
- [x] R1.17 Startup speed: how long the computer takes to start and what slowed it down (Windows' own performance log, `systemd-analyze` on Linux), with a switch for the startup programs behind it
- [x] R1.18 Disk health: what each drive reports about itself (health, temperature, wear, hours, errors) from Windows' storage reports or udisks, a warning on Home when one is failing, and the system's own optimization (`defrag /O`, `fstrim`) on request
- [x] R1.19 Running programs: processor and memory per program (processes grouped), closing one after asking (forcing only if it does not close), never the system's own, other accounts' or the app's; a switch for those that start with the system
- [x] R1.20 Power plan: switch between the system's plans (`powercfg`, `powerprofilesctl`), Windows' power mode shown with a way to its Settings page, and a tip on Home when the plan saves energy at the cost of speed
- [x] R1.21 Virtual disks of WSL and Docker Desktop: what each `.vhdx` takes on Windows against what Linux uses inside, and compacting it (fstrim, `wsl --shutdown`, diskpart `compact vdisk`) as administrator after asking
- [x] R1.22 Old large files: files of 50 MB or more not changed in over a year, found during the scan, without the system's or programs' own files
- [x] R1.23 Restore points: how many and what they take (CIM, in any language), and deleting all but the newest on each drive, as Disk Cleanup does, after asking
- [x] R1.24 Empty folders: found during the scan and checked on the disk (links count as content), without hidden, system, program or project folders; to the recycle bin, each checked again first
- [x] R1.25 Old driver packages: older versions of each driver in the driver store that no device uses, measured and removed with `pnputil` (never `/force`); the newest and every one in use stay
- [x] R1.26 Devices with a driver problem (the yellow mark of Device Manager) named on Home, without changing anything
- [x] R1.27 Home's recommendations gathered in parallel, so Home is ready about as soon as its slowest check (a minute on Windows before)
- [x] R1.14 What changed since the last scan of a folder: the folders that grew or shrank most, as deep as the change goes (summaries kept on this computer)

## R2 — Rewind OS on every system

- [x] R2.1 Rename to Rewind OS (`rewind-os-*`, app id `io.github.rewind_os.rewind_os_app`)
- [x] R2.2 App icon: a rewound cassette tape in the app's navy and blue (was a disk gauge around a rewind symbol, a retro cassette, and before that an engraved raccoon), generated by `assets/app-icon/draw.py`, rendered by `cargo xtask icons`
- [x] R2.3 Every tool declares its systems; unsupported tools say so in the GUI and the CLI
- [x] R2.4 Known folders per system (XDG on Linux, `~/Library` on macOS)
- [x] R2.5 Cleanup categories for Linux and macOS; recycle bin on Linux and macOS
- [x] R2.6 Linux startup programs (XDG autostart, user overrides only)
- [x] R2.7 Linux maintenance: journal size and vacuum
- [x] R2.8 CI on Linux, Windows and macOS; Linux x64/arm64 tar.gz in releases
- [x] R2.9 Linux: installed programs (dpkg, rpm, pacman, Flatpak, Snap), without libraries and the base system
- [x] R2.15 Linux: uninstall through the package manager (APT simulated first, never taking other packages along; pacman, Flatpak, Snap)
- [x] R2.16 Linux: leftovers of removed programs in `~/.config`, `~/.local/share`
- [x] R2.17 Linux: RPM uninstall (`rpm -e`, checked with `--test` first, never taking dependents along)
- [x] R2.10 macOS: installed apps (`/Applications`, `~/Applications`), uninstalled to the Trash
- [x] R2.18 macOS: leftovers of removed apps in `~/Library/Application Support` and `~/Library/Containers`
- [x] R2.11 macOS: LaunchAgents on and off through launchd's own record (`launchctl disable`), never Apple's
- [x] R2.20 macOS: login items ("Open at Login"), which need permission to control System Events
- [x] R2.12 macOS release: a universal `.app` (Apple silicon and Intel) with its `.icns`, signed ad hoc, in a `.dmg`
- [ ] R2.21 macOS: sign with an Apple Developer ID and notarize, so the app opens without a confirmation (needs a paid Apple Developer account)
- [x] R2.13 Linux: `.deb` and `.rpm` packages next to the tar.gz
- [x] R2.19 Linux: Flatpak bundle (host filesystem; system tools run on the host)
- [x] R2.22 Linux: signed apt, dnf and zypper repositories on GitHub Pages, updated by every release and installed from in clean containers first, so `apt`/`dnf`/`zypper install rewind-os` and system updates work
- [x] R2.23 Linux: old kernels in `/boot` removed with the package manager, always keeping the running one and the newest
- [x] R2.24 Leftovers on every system know what no package manager lists: Steam games, audio plugins (VST, CLAP, AAX, LV2, Audio Units), AppImages and `/opt`; checked end to end on each system in CI
- [x] R2.14 Linux and macOS: administrator rights for one action at a time (pkexec / authorization dialog), never a root window

## R3 — Easier and lighter

- [x] R3.1 Sidebar grouped by goal (Free up space, Programs, System)
- [x] R3.2 Lists with row shading, a highlighted row under the pointer and visible row actions
- [x] R3.3 Recommendations on Home, each leading to the action
- [x] R3.4 Make Windows lighter: reversible settings for ads, suggestions, privacy, extras, effects
- [x] R3.5 Optional removal of preinstalled Store apps (reinstallable from the Store)
- [x] R3.6 Recommendations from leftovers and duplicate files (duplicates in Downloads only, to stay quick)
- [x] R3.7 A Termius-like look: navy layers, a tool band on every page, semibold names, list rows as cards, icons on coloured tiles
- [x] R3.8 Installed and startup programs as a grid of cards, with the selected one's details in a panel on the right
- [x] R3.9 A rail of groups (Home, Free up space, Programs, System) with only the current group's pages listed next to it; each group reopens the page last used in it
- [x] R3.10 Recommendations on Home for virtual disks of WSL and Docker that compacting would shrink, and for restore points that take a lot of space (with administrator rights)
- [x] R3.11 Colours in the CLI after the app's look (bold headings, sizes in the accent blue, yellow warnings, red errors), only in a terminal and never with NO_COLOR
- [x] R3.12 CLI progress with the time taken; the first Ctrl+C stops a scan or cleanup and prints what it did so far, marked as stopped (exit code 130), the second quits
- [x] R3.13 The window's own title bar in the app's colours (Windows and Linux: drag, double click to maximize, minimize, maximize and close, resizing from the edges; macOS keeps its own buttons); `REWIND_OS_NATIVE_TITLE_BAR=1` keeps the system's
- [x] R3.14 A dark theme in neutral near-black and greys as in VS Code instead of navy, and a test that text, accents and controls keep their contrast on every layer of both themes
- [x] R3.15 Battery health: the charge each battery still holds against what it was made to hold, and its cycles (Windows' battery report, `/sys/class/power_supply`, `ioreg`), on the health page, in the CLI and as a tip on Home when it is worn
- [x] R3.16 Optional scheduled cleaning of the categories marked safe (Task Scheduler, a systemd timer, launchd), off until turned on, with a report of each run

## R4 — A terminal interface

For computers without a desktop, or reached over SSH: full-screen views in the terminal, driven
by keys like k9s, through the same engine requests as the app and the CLI.

- [x] R4.1 `rewind-os-cli tui`: Home (drives, memory, recommendations), disk scan (folders by size, into and out of them, largest files, stopped with a key) and cleanup (categories to pick, a confirmation, what was freed and kept); views switched with `1`–`3` or `:name`
- [x] R4.2 Startup programs and installed programs, with their details and on/off
- [x] R4.3 Duplicates, program leftovers and build folders: picked one by one, moved to the recycle bin (or, for build folders, deleted) after a confirmation, never the last copy of a file
- [x] R4.4 Running programs (closed or forced after a confirmation, turned off at startup) and maintenance (the system's own tools; what changes the system asks first and needs its rights)
- [x] R4.5 The mouse in the terminal interface (tabs, rows, the wheel, a double click opens a folder) and running programs measured again every few seconds, the cursor staying on the same program
