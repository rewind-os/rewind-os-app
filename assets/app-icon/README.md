# Rewind OS app icon

A **disk gauge around a rewind symbol**: the ring is a drive's usage chart, the two triangles
pointing left say "rewind". Flat shapes on a graphite full-bleed tile, in the app's own colours
(the blue accent of the interface). The ring and the triangles are thick, so the icon still reads
at 16 px.

## Palette

| Colour | Hex | Used for |
|---|---|---|
| Tile | `#1c2433` to `#0c1018` | the tile, a vertical gradient |
| Track | `#2a3446` | the empty part of the ring |
| Arc | `#3b82f6` to `#7cb4ff` | the filled part of the ring, a gradient |
| Mark | `#f4f7fb` | the rewind triangles |

## Geometry

`viewBox="0 0 512 512"`, a rounded-square tile with `rx=112`, clipped; the colour fills the whole
tile. The macOS file (`rewind-os-macos-512.png`) adds Apple's transparent margin (an 824/1024
body); Windows and Linux files use the full-bleed tile.

## Provenance

Original work for this project, generated by `draw.py` (Python standard library) from plain
shapes. No third-party artwork. Licence: `LICENSE.txt`.

## Files

| File | What |
|---|---|
| `draw.py` | the generator; `rewind-os.svg` is its output |
| `rewind-os.svg` | canonical vector |
| `rewind-os-1024.png` | 1024 px render (store listings, docs) |
| `rewind-os-macos-512.png` | runtime window icon on macOS |
| `rewind-os.ico` | Windows icon, 16-128 px as bitmaps (which Windows Installer and shortcuts need) and 256 px as PNG, embedded in `rewind-os.exe` by `apps/rewind-os/build.rs` |
| `hicolor/<n>x<n>/apps/io.github.rewind_os.rewind_os_app.png` | Linux icon theme, 16-512 px; the 256 px one is also the runtime window icon on Windows and Linux |
| `hicolor/scalable/apps/io.github.rewind_os.rewind_os_app.svg` | Linux scalable icon |

## Regenerate

```sh
python3 assets/app-icon/draw.py > assets/app-icon/rewind-os.svg
cargo xtask icons
```

Every output is committed, so building and packaging never need these tools.
