# Rewind OS app icon

A **raccoon**, frontal head-and-shoulders portrait, drawn as an engraving: a full-bleed colour
field, a tight portrait, the figure in paper with ink line work and a crisp ink contour, no
roundel or border. The bandit mask keeps it recognisable down to 16 px.

## Palette (three colours)

| Colour | Hex | Used for |
|---|---|---|
| Ink | `#0c0c0e` | line work, the mask and the contour |
| Paper | `#f0eadf` | the figure |
| Rewind OS teal | `#1a9e8c` | the full-bleed field (the app colour) |

## Geometry

`viewBox="0 0 512 512"`, a rounded-square tile with `rx=112`, clipped; the colour fills the whole
tile. The macOS file (`rewind-os-macos-512.png`) adds Apple's transparent margin (an 824/1024
body); Windows and Linux files use the full-bleed tile.

## Provenance

Original work for this project, generated by `draw.py` (Python standard library, fixed random
seed): a tone map decides the width of each tapered ink stroke and the strokes follow the
direction fur grows in. No third-party artwork. Licence: `LICENSE.txt`.

## Files

| File | What |
|---|---|
| `draw.py` | the generator; `rewind-os.svg` is its output |
| `rewind-os.svg` | canonical vector |
| `rewind-os-1024.png` | 1024 px render (store listings, docs) |
| `rewind-os-macos-512.png` | runtime window icon on macOS |
| `rewind-os.ico` | Windows icon, 16-256 px, embedded in `rewind-os.exe` by `apps/rewind-os/build.rs` |
| `hicolor/<n>x<n>/apps/io.github.r_dvl.rewind_os.png` | Linux icon theme, 16-512 px; the 256 px one is also the runtime window icon on Windows and Linux |
| `hicolor/scalable/apps/io.github.r_dvl.rewind_os.svg` | Linux scalable icon |

## Regenerate

```sh
python3 assets/app-icon/draw.py > assets/app-icon/rewind-os.svg
cargo xtask icons
```

Every output is committed, so building and packaging never need these tools.
